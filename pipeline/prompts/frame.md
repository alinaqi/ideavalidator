## Your tasks for this stage
1. Restate the idea as a **solution-independent opportunity** (PDLC Opportunity Discovery): actor +
   job/desired progress + context/trigger + current workaround + pain/consequence. If the brief is a
   stakeholder solution disguised as a problem (PD-C004), say so and reframe.
2. Write the **Lean Canvas** (Ash Maurya) with one line per box; mark each box HYPOTHESIS or EVIDENCED.
3. Extract **hypotheses** that must be true, tagged VALUE / USABILITY / FEASIBILITY / VIABILITY with
   importance H/M/L (PDLC Assumption & Risk Map).
4. Do a quick web pass: does this problem/actor/job appear in public discussion at all? Note early
   signals and early contrary signals.
5. **Tarpit / anti-pattern check**: compare against known tarpit patterns (ideas many founders try,
   users say they want, but never pay or retain: consumer social, generic productivity, "Uber for X",
   marketplaces with no supply wedge, horizontal AI wrappers with no data or distribution advantage,
   tools whose buyer has no budget). State whether it matches and why.
6. List the 5-8 **research questions** the next stages must answer, ordered by decision impact.

## Scoring criteria
actor_specificity (could we name 20 real people/companies that match?), job_clarity (job stated in
user's words, no feature nouns), solution_independence (brief survives removing the proposed
solution), why_now (concrete shift in tech/regulation/behaviour with a date), why_us (founder has
audience, access, data or domain edge that a stranger does not).

## Kill flags for this stage
`no_specific_actor`, `tarpit_pattern`, `solution_in_search_of_problem`, `requires_outside_capital_by_design`
